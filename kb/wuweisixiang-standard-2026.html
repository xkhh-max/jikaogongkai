五维四型2026合格标准与打分规则

📂 五维四型⏱ 2026年7月

一、五维四型是什么？

五维四型是当前征兵工作中对应征青年进行综合评估的标准框架。"五维"指五大评估维度：文化程度、体质状况、体能水平、心理素质、军事职业适应能力；"四型"即根据综合评定结果将青年划分为四种岗位类型：技能型、体能型、通用型、特殊型（特殊型对应特战、特殊专业技术等岗位）。在此基础上，定兵还会给出推荐等级（I型优先推荐、II型推荐、III型待定、IV型不推荐）。该体系覆盖了从报名到定兵的全流程，是2026年征兵考核的核心依据。

📌 核心逻辑

各维度独立评分 → 加权汇总 → 定兵综合得分 → 四型分类 → 决定入伍资格与兵种分配

二、五维四型2026合格标准（各维度）

1. 文化程度（学历赋分）

学历是五维评分的基础项，在定兵综合分中占固定权重。2026年学历赋分标准如下：

学历层次赋分说明
全日制本科及以上100分含本科毕业（双证齐全）
全日制大专85分含应届/往届大专毕业生
高校新生/在校生70分保留入学资格入伍
高中/中职/技校毕业60分普高、职高、中专、技校
初中及以下40分需通过文化测试补差

2. 体质状况（身体条件评分）

体质维度以征兵体格检查结果为评分依据，主要项目包括：

项目合格区间评分规则
BMI（身高体重比）17.5 ≤ BMI < 30（男）
17 ≤ BMI < 24（女）		正常范围计满分，边缘放宽扣5-10分
肺活量≥ 3200ml（男）
≥ 2400ml（女）		每低200ml扣2分
平衡能力（闭眼单足站立）≥ 15秒每少1秒扣1分
血压收缩压90-140mmHg
舒张压60-90mmHg		超出范围单项不合格

3. 体能水平（各项目合格分数）

体能水平是五维综合素质量化评估中的一个维度（满分100分），依据《国家学生体质健康标准》《国民体质测定标准》制定，考核的都是高中生体测内容。主要项目及参考标准如下：

项目男子参考标准女子参考标准
1000米跑（男）/800米跑（女）约4分30秒以内及格约4分30秒以内及格
立定跳远≥2.30米（及格参考）≥1.80米（及格参考）
坐位体前屈≥2厘米（及格参考）≥3厘米（及格参考）
跳绳参考高中生体测标准参考高中生体测标准
投掷（男）/1分钟仰卧起坐（女）参考高中生体测标准参考高中生体测标准

💪 体能水平训练提示

五维体能考核的都是高中生体测内容，标准公开，自己锻炼即可，无需报班。重点练好1000米跑、立定跳远、坐位体前屈，建议提前2个月开始规律训练。

4. 心理素质（MMPI测试）

通过明尼苏达多项人格测验（MMPI）进行评估。心理维度采用合格/不合格二分类制，不合格者直接淘汰，不纳入加权评分：

  • 均为正常值（T分 < 60）：合格，心理维度计100分
  • 1-2项量表轻度偏高（T分 60-70）：需复查或面谈，根据结果判定
  • 3项及以上量表异常（T分 ≥ 70）：不合格（终止入伍流程）

本平台提供MMPI心理测评在线练习，可提前了解题型和答题节奏。

5. 军事职业适应能力（综合文化机考）

采用机考形式统一考核，内容涵盖：

科目题量占比考核内容
言语理解30题25%阅读理解、词语运用、病句辨析
数量关系20题20%基础运算、方程应用、数列推理
逻辑判断25题25%图形推理、逻辑推理、定义判断
军事常识30题30%国防法规、条令条例、军兵种知识

总分100分，≥ 60分为合格线，低于60分需补考或直接淘汰。

三、五维四型体检标准

体格检查属于体质维度的前置条件，不符合体检标准的应征青年直接淘汰，不进入后续评分流程。2026年核心体检标准如下：

项目合格标准
身高（男）≥ 160cm（条件兵 ≥ 162cm）
身高（女）≥ 158cm
体重（男）17.5 ≤ BMI < 30
体重（女）17 ≤ BMI < 24
裸眼视力（任何一眼）≥ 4.5（矫正视力 ≥ 4.8，矫正度数 ≤ 600度）
色觉色盲不合格；色弱者陆勤人员可合格（特殊岗位除外）
文身瘢痕裸露部位无文身；非裸露部位长径 ≤ 3cm
耳鼻喉鼓膜完整、听力正常、嗅觉正常

具体可参考本平台体检标准自查工具，逐项核对。

四、五维四型定兵打分规则

各维度权重分配

维度权重考核方式
文化程度20%学历证书赋分
体质状况15%体检数据评分
体能水平30%役前体能考核
心理素质10%MMPI + 结构性面谈
军事职业适应能力25%机考成绩

综合评分与定兵关系

综合得分 = 各维度得分 × 对应权重之和。按综合得分将应征青年划分为四型：

类型综合得分定兵结论
I 型≥ 85分优先推荐，可挑选兵种和去向
II 型70 - 84分推荐入伍，由武装部分配兵种
III 型60 - 69分待定，视名额和补录情况确定
IV 型< 60分不推荐入伍（可参加下一批次）

⚠️ 注意事项

任何维度出现一票否决项（如心理不合格、体检不通过），则直接归入IV型，不参与综合评分。各县级武装部可在上述框架内微调权重，具体以当地定兵细则为准。

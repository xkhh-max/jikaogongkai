2026征兵体检项目大全（11大项检查内容+合格标准）

📂 体检攻略⏱ 2026年7月

征兵体检是参军入伍的第一道关卡，直接决定你是否能进入役前训练环节。2026年征兵体检沿用《应征公民体格检查标准》，涵盖外科、内科、眼科、耳鼻喉科、口腔科、心电图、腹部B超、X光胸片、血液检查、尿液检查和心理检测共11大项。本文逐一列出每项的检查内容和合格标准，帮助你在上站前做到心中有数。

一、外科检查

身高体重标准

男性：身高160cm以上，体重17.5 ≤ BMI < 30（空腹血糖正常者BMI可放宽至 < 30，单纯BMI > 30需查空腹血糖排除糖尿病）。

女性：身高158cm以上，体重17 ≤ BMI < 24。

BMI = 体重(kg) ÷ 身高(m)²。体重严重超标或过度消瘦均不合格。

文身疤痕要求

面颈部文身，着军队制式体能训练服其他裸露部位长径超过3cm，其他部位长径超过10cm的文身，不合格。男性文眉、文眼线、文唇，女性文唇，不合格。疤痕存在功能障碍者不合格，其他部位不影响功能的长径3cm以下疤痕通常合格。

扁平足与静脉曲张

重度扁平足（足弓完全消失）不合格。中、重度下肢静脉曲张或精索静脉曲张不合格。

四肢关节功能

手指、足趾残缺或畸形，足底弓完全消失的扁平足，影响功能的关节疾病或损伤，不合格。肘关节过伸超过15度、外翻超过20度，或存在功能障碍，不合格。

二、内科检查

血压标准

收缩压 ≥ 90mmHg 且 < 140mmHg，舒张压 ≥ 60mmHg 且 < 90mmHg。超出范围需复查，连续三次异常不合格。

心脏听诊

听诊发现心脏杂音、心包摩擦音等异常，需进一步做心脏超声排除器质性心脏病。器质性心脏病（风湿性、先天性、冠心病等）不合格。

腹部触诊

触诊发现肝脾肿大、腹部包块等异常，需进一步B超确认。肝大超过肋下1.5cm（排除体型因素）、脾大，不合格。

📌 常见疑问

偶发早搏（每分钟不超过6次）且心脏超声无异常者，通常合格。窦性心律不齐在青年中很常见，一般不影响结论。

三、眼科检查

裸眼视力标准

任何一眼裸眼视力 ≥ 4.5 为合格。任何一眼裸眼视力低于4.5不合格。

裸眼视力4.5~4.8的，需矫正视力检查：矫正视力 ≥ 4.9 且矫正度数 ≤ 600度，合格。

裸眼视力4.9以上，直接合格。

色觉检查

色盲不合格；色弱者陆勤人员可合格（坦克乘员、潜艇及水面舰艇、空降兵、特种部队等特殊岗位除外）。检查使用色盲图谱，在自然光或标准光源下辨认数字或图形。

激光手术要求

屈光不正经准分子激光手术后半年以上，无并发症，任何一眼裸眼视力达到4.8，眼底检查正常，合格。术后时间少于半年原则上不合格（部分兵种严格执行，普通兵种各地执行尺度有差异）。

四、耳鼻喉科

听力标准

双耳听力：在纯音测听条件下，耳语听力5米以内不合格（双耳均低于5米）。一侧听力完全丧失不合格。具体执行：语频平均听力损失 ≤ 25dB HL为合格。

嗅觉检查

嗅觉丧失不合格。使用三种挥发性液体（酒精、醋、水）进行测试，分辨不出两种及以上者不合格。

五、口腔科

缺齿、龋齿、牙周病等影响咬合功能的不合格标准：III度龋齿超过3个、缺齿超过2个（经修复不影响功能者除外）、重度牙周炎和颌关节功能紊乱不合格。错合畸形、反合等影响咀嚼功能者不合格。单纯浅龋（I度、II度）且数量不多，一般合格。

六、心电图

正常心电图范围

窦性心律，心率 60~100次/分，PR间期 0.12~0.20s，QRS时限 < 0.12s，QTc间期 0.32~0.44s，ST-T无明显异常。

常见不合格原因

  • 频发早搏（室性早搏 > 6次/分或二联律）
  • II度II型以上房室传导阻滞
  • 预激综合征（WPW综合征）伴心动过速史
  • 心房颤动或心房扑动
  • 病态窦房结综合征
  • ST-T改变合并临床意义者（单纯非特异性ST-T改变，心超正常且无症状，部分可合格）

⚠️ 注意

心电图初次异常可休息后复查一次。很多因素（紧张、熬夜、饥饿）会导致一过性心电图异常，不要因为一次结果就放弃。

七、腹部B超

检查肝胆胰脾肾：脂肪肝（轻中度、肝功能正常者合格，重度或合并肝功能异常者不合格）；肝囊肿、肾囊肿（单个直径 < 3cm且无症状者合格）；肝血管瘤（直径 < 2cm者合格）；胆囊息肉（直径 < 5mm且无症状者合格）。胆结石、肾结石伴有症状或影响功能者不合格。

八、X光胸片

检查肺结核、气胸、肺大疱、胸膜炎等。活动性肺结核不合格（治愈并满1年无复发者合格）；自发性气胸（反复发作或未彻底治愈者不合格）；肺大疱不合格；胸廓畸形影响呼吸功能者不合格。

九、血液检查

血常规

血红蛋白、白细胞、血小板等主要指标在正常范围。轻度异常（如轻度贫血）需复查，明显异常不合格。

肝功能

谷丙转氨酶（ALT）和谷草转氨酶（AST）超过正常上限2倍不合格。轻度升高需复查，排除脂肪肝、肝炎等病因后可合格。

传染病筛查

  • HIV抗体阳性：不合格
  • 梅毒（RPR/TPPA）阳性：不合格
  • 乙肝表面抗原阳性且肝功能异常：不合格（乙肝携带者肝功能正常者，各地执行标准不同——多数省份按合格处理，建议咨询当地武装部确认）

十、尿液检查

尿常规

尿蛋白、尿潜血、尿白细胞等指标异常需复查。持续性蛋白尿或血尿需进一步排查肾脏疾病，确诊肾脏疾病不合格。

毒品筛查

尿检吗啡、甲基安非他明（冰毒）、氯胺酮（K粉）等毒品筛查，任何一项阳性即不合格（长期服用某些处方药可能引起假阳性，须提前告知医生提供用药证明）。

十一、心理检测

MMPI人格测试（机考）

使用计算机化明尼苏达多项人格测验（MMPI），约399~566道判断题，作答时间约40~60分钟。考察疑病、抑郁、癔症、精神分裂等维度。异常值进入结构性访谈环节。

结构性访谈

MMPI异常者由心理医生一对一访谈，评估心理健康状况和应征动机。严重心理障碍、人格障碍、精神病史不合格。

✅ 心理检测准备

保持正常作息、如实答题即可。心理检测没有对错之分，关键是前后一致、真实作答。刻意"装好"反而容易导致矛盾，被判定为无效问卷。

十二、体检前注意事项

  • 饮食：体检前3天清淡饮食，避免油腻、高蛋白、高糖食物，不饮酒。
  • 作息：体检前1天保证充足睡眠，不熬夜。熬夜会导致转氨酶升高、心率偏快、血压偏高等。
  • 用药：体检前1周尽量不服药（慢性病长期服药者除外）。感冒药、止痛药可能影响肝功能和血常规结果。
  • 饮水：体检当天早晨空腹（禁食8~12小时），可少量喝白开水，不影响抽血结果。
  • 穿着：穿宽松衣物和运动鞋，方便外科体检和X光检查。
  • 心态：保持平稳心态，过度紧张会导致血压升高、心率加快，影响心电图和内科检查。
